# Memory model

The project distinguishes several conceptual state layers:

- **Global memory:** facts and experiences belonging to Ester's shared identity.
- **Private user memory:** authorized information scoped to one user.
- **Relationship state:** the evolving relationship between Ester and one user.
- **Session context:** the active conversation and its local continuity.

Synthetic example: a user may opt in to remembering that they prefer concise explanations. That preference belongs only to that user's private memory and relationship context; it must not appear in another user's context. No real private memory examples are published here.
