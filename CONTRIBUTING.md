# Contributing

Ester is experimental research. Contributions are welcome in evaluation, public conversational datasets, training tooling, runtime design, documentation, and reproducibility.

Please provide clear provenance and keep examples public or synthetic. Do not submit private conversations, personal memory dumps, credentials, holdout material, model weights, or copyrighted/private datasets without authorization. Contributions should not imply that Ester is stable, sentient, AGI, or human-equivalent.
